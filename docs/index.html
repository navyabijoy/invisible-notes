Almost there!

Ghost Notes isn't code-signed yet, so your OS may show a warning.
Here's how to get past it:

Windows
  1. Run the downloaded .exe installer.
  2. Windows SmartScreen may show "Windows protected your PC".
  3. Click "More info" to reveal the option.
  4. Click "Run anyway" to proceed.
macOS
  1. Open the downloaded .dmg and drag Ghost Notes to Applications.
  2. On first launch, macOS may say "Ghost Notes can't be opened because Apple cannot check it for malicious software."
  3. Open Terminal and run the command below to allow it:
xattr -cr /Applications/Ghost\ Notes.app

Then open Ghost Notes again, it will launch normally from now on.
